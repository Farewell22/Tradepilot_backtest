# N型回调守前低：AMV主仓开仓日截面研究

仅使用冻结策略运行 `amv_winning_defensive__20260928T143530Z__de469ebc` 的农行账户交易文件，读取其中买入512100的51个日期（2020—2025年）。对这些日期的历史A股截面计算因子，不修改原策略，也不把所有0AMV买入信号当作实际开仓。

## 定义

`L0 → H1 → L1 → H2 → L2 → H3 → L3(t)`。要求 `H1<H2<H3` 且每段上涨高点高于起点低点，当日收盘不高于H3。主因子 `F=min(L1/L0−1,L2/L1−1,L3/L2−1)`；高值表示三轮中最弱的一轮仍较好守住前低，负值表示至少一次破低。没有三轮结构等状态不填0或50。

先跟踪低点，以收盘较最低价回升5%确认谷点，再跟踪高点，以收盘较最高价回落5%确认峰点。每日先更新候选极值，最多确认一次；同价取最后出现日；下一候选从已确认极值的次日起初始化，避免猜测日内先高后低的次序。发生日与确认日分开保存，观察日只使用当时已确认的前序点；第三轮L3为H3之后截至观察日的最低价，不等待未来确认。

因子窗口为252根有效日K，读取首个观察日前504个市场日预热。3%和8%阈值为预定稳健性对照，不按结果选参数。

## 数据与复权

本地 `data/backtest_data/5m_price` 聚合日OHLC，要求完整48根5分钟K（可加09:30），检查排序、重复、有限正价格、OHLC关系及正成交量。无效日不造价，停牌日不填价格。历史股票池包括沪深A股与北交所，排除689xxx存托凭证（CDR），不使用今天的上市名单；因缺少可靠历史ST状态，保留ST。

原始价格存在除息跳空。准备阶段最初验证过Tushare，但批量请求返回40203限频，实际使用新浪 `https://finance.sina.com.cn/realstock/company/<市场><代码>/hfq.js` 的历史复权事件。解析JSON而非执行JS；检查事件数量、日期、正乘数及起始覆盖，缓存来源、取得时间与SHA-256。明确事件的乘数仅从生效日起延续，任何股票复权数据缺失则失败，不以未复权替代，不混合两个供应商。

证券类型修正依据：[上交所2020年市场资料第23页](https://www.sse.com.cn/aboutus/publication/factbook/documents/c/10170562/files/da4f403a0b7443fa9b2ba2e002d38f10.pdf)将688股票与689存托凭证分列。全量校验时689009的复权接口返回空数据，核验证券类型后修正原有过宽的6开头筛选。日线缓存保留原始记录，准备阶段按类型排除，逐日审计记录`excluded_cdr_rows`，准备缓存版本升级；不是按因子或收益筛选。

统一价格 `P*=P×A`，其中A是该日已生效的累计乘数。它与以观察日为基准的前复权仅差一个共同缩放，故本研究所有价格比率、拐点门槛和标签一致；不使用未来乘数缩放历史因子。缓存位于被忽略的 `data/factor_research_data/n_pullback_amv_entry/`，可中断续跑。供应商历史修订没有完整的逐时点档案，这是研究限制。

## 收益与统计

`R_h(t)=P*_close(t+h)/P*_open(t+1)−1`，h=5/10/20，按市场交易日历计算；不按个股下一可交易日顺延。缺失入口或目标日行情则对应标签缺失，窗口各自处理。MAE使用完整市场窗口内最低价/入场开盘−1，若中间日缺失则MAE缺失。标签不计费用、不代表涨跌停日一定能成交；退市清算收益未建模。

先在每个日期独立计算股票组收益，再日期等权汇总。基准是当日有至少252根有效历史日K的全体A股在该窗口的可用收益等权平均，不要求N型。统计全N型、三轮均守前低（F>=0）、破低（F<0）、非N型及五分组；因子分组不依赖未来标签。同分用平均秩，不人为拆开，可能出现空组。五分组至少50样本且5种分值，IC至少30样本且因子/标签均有变异。

报告均值、中位数、上涨比例、超额收益、Q5-Q1、IC和MAE。区间按相交市场收益窗口连接成簇，簇bootstrap2000次、种子42，保留日期等权；少于10簇不报告区间。各组和对照差值的区间以相应可用日期为基础。分2020—2023、2024—2025及年度展示，不称为严格未知样本外，不做多重检验调整。
