# etf_size_rs20_percentile

研究中证1000 ETF（512100.SH）相对上证50 ETF（510050.SH）的20日强弱，在最近100日中的百分位，是否与两只ETF随后各自收益和相对收益有关。

```bash
./scripts/backtest.sh list research
./scripts/backtest.sh run research etf_size_rs20_percentile --start 20200101 --end 20251231
```

默认正式区间为2020—2025年。日期只约束因子观察日，标签可使用之后已经存在的行情；截至2025年底的未来不足记录按期限单独置空。

## 定义与时间对齐

- 输入为未复权60分钟行情，按实际时间排序后聚合日线。两只ETF的日期必须一致，每日必须有完整4根行情；未知缺失、非法价格和未知零成交日直接报错。
- 时钟为两只ETF共同有成交的交易日。512100在2022-09-02停牌，原文件保存了4根零成交旧价格，该日从两只ETF时钟中同时剔除。
- 依据独立公司行动表构造总收益指数：`T(t)/T(t-1) = [s(t) × C(t) + D(t)] / C(t-1)`，其中`s`为新份额／旧份额，`D`为每份旧份额现金分红。归一化起点为100，不影响任何区间收益。
- 分红于除息日收盘再投资；512100合并比例0.36555在2022-09-05的实际报价切换日应用。公告日期、除息日期、到账日期和来源另行保存。
- `RS20 = T1000(t)/T1000(t-20) - T50(t)/T50(t-20)`；百分位使用`t-99..t`的100个有效RS20：`100 ×（较低值数量＋0.5 × 相同值数量）/100`。完整预热需要119个此前交易日，年初不重置。
- `R_i,H = T_i(t+H)/T_i(t)-1`，期限5、10、20、60日。`spread = R_1000,H - R_50,H`，始终使用同一日历与相同端点。
- 事件核对范围2019-01-01—2025-12-31，2019年仅用于默认任务预热。未经核对的更早或更晚区间不接受。

## 统计与解读

固定百分位档位为`[0,10)、…、[90,100]`，空档仍输出，避免按未来全样本分位数生成阈值。每个档位、期限和收益目标保存数量、缺失标签、平均数、中位数、胜率、P10/P90和同期限全样本基线。

相关性为**时间序列**Spearman，不是两个ETF之间的横截面IC。全样本、2020—2023及2024—2025估计IC和最高档减最低档效应；120日移动分块bootstrap重复2000次，种子42，95%区间。重采样在删除缺失标签之前进行；至少需要240个有标签观测，少于95%的重采样有有效效应时不提供该区间。年度统计仅描述。

每个期限输出全部H个非重叠起始相位，按完整共享日历的位置取模，不在每年重新开始。样本窗口会重叠，不能将每日观测数等同于独立交易数。

强百分位不等于RS20为正，更不等于任何一只ETF绝对上涨。先看两只ETF的绝对收益，再看收益差；是否反转或延续需同时检查时期、年度、置信区间及非重叠结果。多窗口结果为探索比较，后段称为时间稳定性检查，不称为未触碰样本外。

## 产物

完整输出位于`data/factor_research_runs/etf_size_rs20_percentile__*`：

- `observations.csv`：逐日因子、总收益指数、分档、各期限端点及标签；收益为小数。
- `summary.csv`：分组统计；收益显示为百分比，收益差单位为百分点。
- `effects.csv`、`nonoverlap.csv`：相关性、效应区间、年度／时期和所有非重叠相位。
- `data_audit.json`、`metadata.json`：数据覆盖、排除记录、公司行动证据与方法参数。
- `inputs/`、`source_snapshot/`、`execution_metadata.json`：实际输入副本、运行代码副本及SHA-256。
- `quantile_returns.png`、`annual_stability.png`和`report.md`：独立图表与完整统计报告。
- `run_manifest.json`：统一入口生成的状态、日期、数据源和Git状态。

统一入口成功后更新本目录`latest-report.md`。中文研究解读另存`docs/factor-result/`。

总收益假设即时再投，忽略派息到账延迟与合并零碎份额的账户进位；不模拟交易费用。共同供应商在两份文件同时缺失某日的情况，没有独立交易所日历时不能排除。研究揭示两种ETF风格组合的关联，不能单独识别市值因果效应。
