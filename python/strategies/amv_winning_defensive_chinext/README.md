# 创业板指 ETF＋农业银行直接防守

进攻主仓采用跟踪创业板指的易方达创业板 ETF `159915.SZ`。
农业银行 `601288.SH` 的直接防守规则与原 `amv_winning_defensive` 相同；
复用中证2000版本的主仓对照流程，一次运行同时重跑同期 `512100.SH`＋农行基线。

```bash
./scripts/backtest.sh run strategy amv_winning_defensive_chinext \
  --start 20230914 --end 20251231
```

默认区间与中证2000实验相同，为2023-09-14至2025-12-31，556个交易日；
两组各从20万元现金、无持仓开始，便于比较三个进攻主仓。可用 `--config` 更换输入路径及初始资金，
`--start`、`--end` 修改区间。已核实的全天停牌按下文从两组时钟共同剔除；其他缺日直接报错。
本地159915行情覆盖2011-12-09至2025-12-31，农行输入与分红表支持本次2020—2025年区间。

```bash
./scripts/backtest.sh run strategy amv_winning_defensive_chinext \
  --start 20200101 --end 20251231
```

## 2020—2025年停牌处理

`calendar_policy.json`记录两个有公开公告依据的全天停牌：

- 159915于2021-02-08因持有人大会计票停牌，2021-02-09 10:30复牌。
  [基金停牌公告](https://pdf.dfcfw.com/pdf/H2_AN202102081459963456_1.pdf)、
  [复牌时点记录](https://www.cindasc.com/osoa/views/a/20210209/42396.html)。
- 512100于2022-09-02因份额合并停牌，2022-09-05复牌；合并比例0.36555。
  [基金合并公告](https://static.cninfo.com.cn/finalpage/2022-09-01/1214507899.PDF)。

两天同时从两个账户的交易、NAV和银行止盈检查时钟剔除；2020—2025年由1455个市场交易日变为1453个共同可交易日。
0AMV均线、MACD及单日/两日涨幅在完整历史上预先计算，之后再剔除日期，指标的日数定义不变。
原始行情文件保持原样，512100的零成交旧报价不作为可交易价格；0.36555的持仓折算在9月5日新报价边界应用。
同时剔除159915在2020-12-16 10:30与复牌日2021-02-09 10:30的两根零成交占位K线，避免用占位线触发成交。
若公告停牌日反而存在有成交行情，审计校验报错；未知缺日仍报错。

这是一致时钟的比较假设，未逐日模拟“某只ETF停牌、另一只继续交易”及停牌期间银行的盘中止盈。
跨过剔除日期的价格变化在下一观察日体现；历史结果只有在区间、费用和交易日时钟一致时才能直接比较。
`calendar_audit.json`逐项列出实际剔除日期、原因、来源和零成交K线；政策文件也保存至输入快照并计算SHA-256。

## 买卖与风控

- 0AMV单日或两日累计增长≥4%，且收盘≥MA5时卖出农行、全仓买入159915。
- 0AMV收盘低于MA10或MACD(12,26,9)当天死叉时卖出主仓、全仓买入农行；离场优先。
- 主仓买入后的交易日起，跌破成交买价的97.5%硬止损。某日最高价超过成交买价105%，
  收盘后启用前日实体低点跟踪退出；跟踪线每天更新，不保证只升不降。
- 主仓盘中退出后先持现金，当天不回买主仓；当天另有0AMV离场条件仍转入农行。
- 农行买入后的交易日起，净价差收益扣除交易费用后达到8%全仓止盈，分红不参与阈值；
  跳空越过阈值按开盘价卖出。止盈后现金锁定至下次有效主仓入场，无独立止损。
- 主仓使用60分钟、农行使用5分钟K线检查触价；按100份/股取整，剩余现金及股息不自动增持。

## 费用、输出及限制

ETF佣金双向万三、最低5元，双向滑点0.1%，无印花税/过户费；农行共享佣金和滑点，
另固定卖出印花税0.1%、双向过户费0.001%。CLI佣金、最低佣金及滑点覆盖同步作用于两类标的；
印花税、过户费覆盖仅作用于主仓，农行沿用固定旧税率。
农行沿用原分红表、持仓资格及除息日税前现金分红模型；未扣个人股息税。ETF不另加现金分红。
512100的份额折算仅用于基线，不用于159915。

根目录为创业板版本，`baseline/`为中证1000版本，均有净值、买卖流水、成对交易、信号和绩效。
`annual_returns.csv`、`comparison_nav.csv`、`report.md`保存年度及同期对照。
`inputs/`、`code_snapshot/`、`source_manifest.json`保存实际输入、配置、依赖代码与SHA-256；
统一入口保存运行清单，并仅在成功时更新本目录 `latest-report.md`。

年化按实际起止日及365自然日复利，夏普按243交易日、零无风险利率；胜率和交易数合计主仓与农行闭合交易。
期末持仓按收盘价估值，不强制平仓。成交仍为 `legacy_same_close_idealized`：收盘确认0AMV信号，
按同日收盘成交，属于理想化假设；未模拟涨跌停、停牌不可成交、盘口容量、股息税及股息到账延迟。
