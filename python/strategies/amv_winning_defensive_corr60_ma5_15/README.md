# 满仓MA5弱入场：0AMV单日涨幅至少1.5%

在amv_winning_defensive_corr60_ma5上仅过滤弱信号。弱信号为昨日0AMV收盘≤昨日MA5、今日收盘>今日MA5、单日涨幅≥1.5%，且非原高质量信号。被过滤的上穿不延迟补买。原强信号仍为单日或两日累计≥4%且收盘≥MA5，不受弱门槛限制。

初始20万元，全仓100份取整；开仓按当日corr60最高值选ETF，持仓不按排名轮换。使用原固定去重无25%疑似断点池。没有MA60门槛。

弱仓按入场0AMV涨幅冻结净阈值：≥1.5%且<3%止损−1.25%/止盈+2%；≥3%止损−1.5%/止盈+2.5%。买入当日不盘中卖出，买入后第3个共同交易日收盘时间退出。开盘跳空按开盘，同根双触价止损优先。
弱仓原ETF遇强信号升级，不交易、不重置成本/买入日期；原2.5%硬止损及5%后实体低点跟踪恢复。升级当日只按收盘新激活利润保护。
顺序为盘中退出→AMV收盘退出→升级→时间退出；退出当天禁止重开进攻仓。AMV跌破MA10/MACD死叉优先；保留原红利低波或农行防守规则、农行8%净价差止盈和分红。
