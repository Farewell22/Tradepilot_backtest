# 0AMV 均线下方的防守 ETF 策略

MA30、MA60 各自独立测试银行（512800）、电力（561560）、煤炭（515220）、红利低波（512890），比较各自买入持有、沪深300（510300）同条件择时/买入持有和零收益现金，共16条曲线。

在项目根目录运行：

```bash
./scripts/backtest.sh run strategy amv_below_ma_defensive_etfs --start 20220516 --end 20251231
```

省略日期参数时默认运行2022年5月16日至2025年12月31日；已核对公司行动的区间也是此范围，日期可在区间内缩短。每个独立账户初始20万元，默认 ETF 费用为双向佣金0.03%（每笔最低5元）、滑点0.1%，无印花税和过户费。统一命令的费用覆盖参数对全部非现金组同时生效。

收盘后，以当天及以前的0AMV收盘计算简单均线：严格低于对应均线时，下一交易日09:30开盘用可用现金买入；大于等于均线时下一交易日开盘全部卖出。均线用区间前历史预热，首日开盘使用区间前一交易日的信号。日开盘取60分钟行情首根10:30记录的开盘，收盘取15:00记录；信号不会使用成交日最终收盘。

使用未复权行情，独立处理实际 ETF 派息和份额拆分。登记日收盘锁定资格，除息日记应收分红，到账日收盘转现金，仍满足持有条件则下一交易日开盘补买。退出优先；不足100份时保留现金，等待下次派息或新开仓。卖出后应收款继续保留，期末持仓和应收款计入净值，不强制平仓。逐批检查T+1，补买与原持仓共用一个持有区间，卖出时整笔计一次最低佣金。

现金派息来源及单位见 `corporate_actions.csv`、`corporate_action_audit.json`。银行、电力、红利低波在核对区间内没有现金派息；基金内部收到的成份股分红已包含在资产价值中。煤炭2024年及银行2025年的1:2拆分显式调整份额和单位成本。公告中的每10份分红已换算成每1份，不计入区间外的登记日事件。

每次运行生成 `summary.csv`、`nav.csv`、`trades.csv`、`episodes.csv`、`corporate_action_ledger.csv`、`annual_returns.csv`、两张净值/回撤图和 `report.md`。`run_manifest.json` 记录命令、费用及修订；`execution_metadata.json` 和 `source_snapshot/` 保存实际输入、代码和 SHA-256。源码目录的 `latest-report.md` 指向最近一次成功运行。

收益和回撤均包含费用、派息及现金余额。区间胜率只统计已经卖出的持有区间，补买不额外增加区间数；年化按365个自然日，夏普按252个交易日且无风险收益为零。对齐日历和完整行情，不默默取缺失数据交集。本策略未模拟涨跌停无法成交、盘口容量或排队，2022年为部分年度。
