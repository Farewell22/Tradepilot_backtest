# 中证2000 ETF＋农业银行直接防守

将 `amv_winning_defensive` 农业银行直接防守方案的进攻主仓由中证1000 ETF
`512100.SH` 替换为华泰柏瑞中证2000 ETF `563300.SH`，其余规则保留。
每次运行同时重跑同期原主仓方案，两个独立账户各从20万元现金、无持仓开始。

```bash
./scripts/backtest.sh run strategy amv_winning_defensive_csi2000 \
  --start 20230914 --end 20251231
```

## 交易规则

| 环节 | 规则 |
|---|---|
| 主仓入场 | 0AMV单日或两日累计涨幅≥4%，且收盘≥自身MA5；卖出防守仓，全仓买入主仓 |
| 转入农行 | 0AMV收盘低于MA10，或MACD(12,26,9)当天死叉；卖出主仓，全仓买入601288.SH；离场优先 |
| 主仓硬止损 | 买入后的交易日起，跌破成交买价的97.5%；跳空跌破按该根开盘价，否则按阈值价卖出 |
| 主仓跟踪退出 | 买入后某日最高价严格超过成交买价的105%，收盘后启用；之后跌破前一交易日日K实体低点退出；实体低点为min(开盘,收盘)，每天更新，不保证单向上移 |
| 主仓盘中退出后 | 先持现金，当天不再买回主仓；当天收盘另有0AMV离场条件则买入农行 |
| 农行止盈 | 买入后的交易日起，费用后净价差收益达到8%全仓止盈；跳空越过阈值按开盘价卖出，否则按阈值价卖出；分红不参与阈值计算 |
| 农行止盈后 | 持现金，连续0AMV离场条件不再买入农行，直到有效主仓入场解除锁定 |
| 防守退出 | 下一次有效主仓入场时卖出农行、买回主仓；农行不设独立止损、不要求周线J条件 |

主仓使用本地60分钟K线，农行使用本地5分钟K线。信号函数、盘中退出顺序、
整百份/股交易及余款处理均复用原版。原版512100的份额折算仅作用于512100。

## 数据与费用

默认路径见 `config.yaml`，支持 `--config PATH`；相对路径均相对项目根目录。
本地563300数据为2023-09-14至2025-12-31，共556个交易日，每日四根60分钟K线。
默认回测完整区间；请求越过其数据覆盖时只使用实际可用区间并在报告中记录，
上市前不回填。交易日取实际区间内两只ETF与0AMV日期的并集，各输入缺日直接报错。
0AMV指标先用完整历史预热，再截取交易区间。农行按原版加载同一份parquet价格与分红表。

默认初始资金200000元，可在配置中设置 `initial_cash`。
ETF双向佣金万三、最低5元，双向滑点0.1%，无印花税和过户费。
农行共享佣金、最低佣金和滑点，另固定卖出印花税0.1%、双向过户费0.001%。
CLI费用覆盖与原入口一致：佣金、最低佣金、滑点同步作用于两个账户的ETF和农行；
印花税、过户费覆盖只作用于主仓费用，农行保留上述固定旧税率。
农行符合原模型持仓资格时在除息日计税前现金红利，现金红利不重复计入卖出现金；
未扣个人股息税，分红现金不自动增持。ETF沿用输入价格口径，不额外记现金分红。

## 输出与比较

- 根目录：新版的 `nav.csv`、买卖流水 `trades.csv`、闭合交易 `paired_trades.csv`、
  `amv_signals.csv`、`metrics.json`。
- `baseline/`：同区间、同信号、同资金、同费用的512100＋农行对照结果。
- `report.md`、`annual_returns.csv`、`comparison_nav.csv`、`verification.json`：
  汇总、年度收益、同期逐日净值及日期一致性检查。
- `inputs/`、`code_snapshot/`、`source_manifest.json`：两个主仓输入、实际农行行情、
  0AMV预热数据、分红表、实际配置、执行代码及SHA-256；统一入口另写 `run_manifest.json`。
- 统一命令成功后更新本目录 `latest-report.md`；失败运行保留上一份成功报告。

总收益、年化、回撤、夏普、胜率及交易数均按原绩效函数计算；胜率和交易数合计主仓与农行的闭合交易。
年化按实际起止日间隔、365自然日复利，夏普按243交易日、零无风险利率。
年度首年仅覆盖实际起点至年末；后续年份相对上年末净值。期末持仓收盘估值，不强制平仓。

成交口径为 `legacy_same_close_idealized`：收盘后才能确认的0AMV信号按同日收盘成交，
属于理想化假设。未模拟涨跌停、停牌不可成交、盘口容量、股息税及到账延迟。
本次只比较更换进攻主仓的结果，不与原策略2020—2025全区间收益直接比较。
