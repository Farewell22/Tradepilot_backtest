# 0AMV 主仓 / 招商银行

独立正式入口：主仓 512100.SH，备选股招商银行 600036.SH。一次命令同时运行此前农行对照的两版。

```bash
./scripts/backtest.sh run strategy amv_winning_cmb --start 20200102 --end 20251231
# 也可从项目根目录按模块运行独立脚本
~/python_env/B1_RATE/bin/python -m python.strategies.amv_winning_cmb.runner --start 20200102 --end 20251231
```

默认初始资金 200,000 元。各版本都保留银行 8% 固定止盈、无止损，主仓有效进场时卖出所有银行并买主仓，100 股整手全仓（保留零头），股票买入当日不卖。

- `direct`：沿用 `amv_winning_defensive`，0AMV 收盘离场立即买入银行；主仓单独盘中止损后持现金。银行扣除买卖费用后的净价差达到 8% 止盈，分红不计入止盈阈值；止盈后持现金直到主仓实际进场。主仓盘中止损当天不再进场。
- `weekly_j`：沿用 `amv_winning`，实际卖出主仓后开始观察；本股当日动态周线 KDJ(9,3,3) 的 J<10 才全仓买入。银行成交买价上涨 8% 止盈，目标价向上取整至分；止盈后次日继续观察。主仓盘中止损后当日可依有效信号重新进场。

主仓信号与止损按原循环，收盘离场与进场冲突时离场优先。两版的差异包括上述再进场与止盈口径，不能把全部收益差异归因于 J 过滤。

数据使用本地 `5m_price` 中该股的未复权行情，成交额/股数检查价格是否为原价；2019 年行情预热本股周线。指标仅按已发生的分红做向前连续处理，执行用原价；现金股息按上一交易日持仓于除息日入账一次。分红金额与 A 股日期核对[招行官方记录](https://english.cmbchina.com/cmbir/intro.aspx?curchnl=Dividend&type=StockInfo)，分红表每行列出 A 股实施公告核对除息日与无送转。2025 中期每股 1.013 元在 20260116 实施，不提前计入 2025 回测。2019—2025 为核对范围，超过 20251231 会拒绝运行。请求期间所有主仓交易日必须同时有银行及 AMV 数据，缺口报错。

费用与农行比较一致：主仓佣金万三、最低 5 元、双向滑点千一；股票另卖出印花税千一、双向过户费十万分之一。可用 `--config` 覆盖输入与初始资金/股票费用。统一入口费用覆盖传给主仓，并将佣金、最低佣金、滑点传给股票；配置中的 `bank_fees` 再覆盖股票费用。

保留 `legacy_same_close_idealized`：收盘确认信号按同日收盘成交，盘中用 OHLC 触价成交；未模拟个人股息税、历史税率变化、停牌涨跌停成交及容量。这是旧口径回测比较。

请求区间每天的周线 J 必须有效；预热不足或缺少有效价格区间时明确报错，不能静默禁用银行入场。无交易区间的 CSV 仍有表头。

产物在独立 `data/backtest_runs/amv_winning_cmb__.../`。`direct/` 与 `weekly_j/` 各有 NAV、成对交易、绩效及报告；直接版保留事件流水。根目录主结果为直接版，另有年度比较、原持现金基准、周线指标、期末持仓、原始输入与代码快照/SHA256、运行 manifest。成功后本目录 `latest-report.md` 保存最新报告。
