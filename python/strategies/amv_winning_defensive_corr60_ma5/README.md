# 动态进攻仓：MA5上穿弱信号与分档退出

```bash
./scripts/backtest.sh run strategy amv_winning_defensive_corr60_ma5 --start 20190118 --end 20251231
```

## 三组同期对照

每组同时测试512890红利低波和601288农行防守：baseline只使用当前corr60策略的原高质量开仓；control增加MA5上穿、保持原退出；ma5新增分档弱仓退出与强信号升级。
相同候选池、共同交易日、费用、初始20万元。进攻仓全仓、100份取整；实际开仓时选择60日相关性第一名，持仓不按排名轮动。

高质量信号：0AMV单日或两日累计≥4%，且收盘≥MA5，保持原条件。
弱信号：昨日收盘≤昨日MA5、今日收盘>今日MA5，且不是高质量信号。没有MA60或最低涨幅门槛；即使当日涨幅非正也可以上穿，使用最低分档。
MA10跌破/MACD死叉退出优先于任何开仓。无合格ETF则保留防守或现金。

## 弱仓退出：ma5组

根据开仓日0AMV涨幅冻结分档，净收益以实际买入总成本为基准，计入双边佣金与滑点：

| 涨幅 | 净止损 | 净止盈 |
|---|---:|---:|
| <1.5% | −1.0% | +1.5% |
| ≥1.5%、<3% | −1.25% | +2.0% |
| ≥3% | −1.5% | +2.5% |

费用函数反求触发报价，不使用0AMV涨幅直接当ETF价格幅度。弱仓买入当日不盘中卖出；最迟买入后第3个共同交易日收盘退出。
开盘跳空越过阈值按开盘；单根K线同时触及上下界时，未跳空则止损优先。跳空和费用会使实际亏损超过净止损目标。
任何弱仓退出当天不重新开进攻仓；如果当天收盘有0AMV退出信号，仍按原规则买防守。

弱仓持有期间出现高质量信号，原ETF升级为强仓，不换标的、不交易、不重置买入价、成本或日期。
升级取消弱仓净止盈止损和期限，转用原2.5%硬止损及超过5%后的实体低点跟踪止盈。
升级当日以收盘判断5%激活，不能使用升级之前的盘中最高价新激活；后续日沿用原最高价规则。
处理顺序：盘中退出→收盘0AMV退出→强信号升级→弱仓时间退出。盘中已经退出的仓位不能在收盘追溯升级。
control组始终采用原退出规则；升级只改变记录标签，不改变退出价格或利润激活状态。

## 费用、数据与限制

沿用corr60策略ETF与股票费用、农行8%净价差止盈和分红、红利低波拆分处理。
原始ETF价格未包含完整复权和现金分红；采用完整历史至20251231无25%价格断点固定池，存在前视偏差。
名称代理去重不能等同于官方指数映射或上市日。
同日收盘信号及因子按同日收盘成交，execution_mode=legacy_same_close_idealized，属于理想化假设。
60分钟OHLC无法判断同根触价先后，未模拟盘口容量、停牌/涨跌停成交约束、个人股息税。
参数仅为预先固定的测试起点，不能据回测择优后宣称未来可复制。

指标另记录佣金/税费/滑点估计、累计成交额与初始本金之比、强弱买入数、升级数以及高质量信号当天被退出阻挡的次数。
