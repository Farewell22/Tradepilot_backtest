# 0AMV防守：开仓选择60日相关性最高ETF

```bash
./scripts/backtest.sh run strategy amv_winning_defensive_corr60 --start 20190118 --end 20251231
```

## 候选池与选股

使用本地ETF 60分钟行情。逐日要求10:30、11:30、14:00、15:00四根完整K线、有效OHLC及正日成交量，完全重复记录先去重，冲突记录对应日无效。
固定池按所有可用历史至2025-12-31筛选：相邻有效收盘或隔夜开盘绝对变化超过25%的基金整只剔除。
这是使用未来数据的事后股票池，存在前视偏差，仅用于本次探索性回测，不能当作当时可知的交易池。
小于25%的除权、数据异常可能残留。

实际开进攻仓时，选择截至当日收盘的ETF日收益率与0AMV日变化率Pearson相关性最高的ETF。
必须有60对完整市场日收益、61个连续收盘，缺失日不填充，不取相关性绝对值，不另设正相关门槛。
按名称保守归一化分组，选择最早有有效行情且因子有效的代表，再选相关性第一名；同分按代码排序。
名称与首条行情是指数、上市日代理，可能误合并或漏合并。
持仓期间不按排名换仓，退出后重新开仓重新选股。无候选时保留防守或现金；持仓行情缺失报错，不删除交易日。

## 原规则保留

初始20万元，满仓、100份/股取整。0AMV单日或两日累计涨幅≥4%，并且收盘≥MA5时允许入场；跌破MA10或MACD死叉退出，退出优先。
进攻仓2.5%硬止损；最高价超过买入执行价5%后启用上一交易日实体低点跟踪止盈。
盘中退出后持现金，当天禁止重开进攻仓；若收盘又有0AMV退出信号则买防守仓。
买入当天不执行盘中卖出。每次换进攻标的重置参考价格、跟踪低点和盈利激活状态。

同时测试512890红利低波、601288农行两个防守版本，保留原防守规则。
农行买入后交易日起使用5分钟行情、扣费用后的8%净价差止盈；止盈后持现金直到有效进攻仓买入。
红利低波无独立止盈止损。农行公开现金分红和512890已核实份额拆分沿用原记账。
每次运行同时重跑两种固定512100进攻仓基线，使用相同共同交易日；动态ETF止损不同可能改变后续实际开仓日期。

## 执行与费用

信号、因子均使用当日收盘，按同日收盘成交，manifest标记legacy_same_close_idealized；这是理想化成交假设。
ETF默认佣金万三、最低5元、单边滑点千一，无印花税和过户费；农行沿用股票费用，佣金/最低佣金/滑点随运行覆盖参数同步。
未模拟涨跌停、停牌成交限制、盘口容量。动态ETF按原始价格成交，未取得完整复权和现金分红资料；不得将结果视为完整总回报或实盘可实现收益。
