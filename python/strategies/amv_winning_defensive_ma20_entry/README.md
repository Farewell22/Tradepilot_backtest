# 农行直接防守：MA20确认第二买点实验

独立策略 `amv_winning_defensive_ma20_entry`。保留单日版的0AMV单日涨幅≥4%
第一买点，增加上穿MA20后的5个交易日确认第二买点。主仓512100.SH，防守仓
农业银行601288.SH。每次运行同时回测同输入、同费用、同成交时点的单日基线。

第二买点：前一日0AMV不高于MA20、当日高于MA20，开启候选窗口。
上穿日为第1个交易日；第1—5日中，首次同时满足三日累计涨幅
`close(t)/close(t-3)-1 > 4%`、收盘>MA60时确认，第6日起失效。
没有确认时不买入；确认后的日期也不持续重复触发。
候选采用完整0AMV历史预热，在确认日生成信号，不回填到上穿日。
共享实现位于 `python/factors/amv_confirmation.py`，按日期顺序推进。

两类均要求0AMV收盘≥MA5，离场优先。任一有效买点在没有主仓时全仓整手买入512100，
持有农行则先全部卖出。当日同时满足两类条件，交易归因于第一买点。
第二买点不包含之前的P60–P80乖离度条件，也不包含MA10次级上穿信号。

成交与退出复用已验证的农行直接防守回测：收盘确认，下一共同交易日开盘执行；
主仓买入日不可卖出。0AMV低于MA10或MACD死叉优先离场转农行；主仓盘中2.5%
硬止损、盈利超过5%后按前日实体低点跟踪退出。盘中主仓离场取消当天买入信号。
农行无止损、费用后净价差8%止盈，股息不计入阈值；止盈后持现金直到有效主仓买点。

```bash
./scripts/backtest.sh run strategy amv_winning_defensive_ma20_entry --start 20200102 --end 20251231
```

默认初始20万元、执行口径 `next_open_amv_abc_t1`。支持 `--config` 选择冻结输入：
`stock_data` 可以是股票分区parquet目录或已归一化的CSV，其他路径含义与原策略相同。
缺少任一主仓交易日的0AMV或农行行情时会报错。

根目录为双买点，`baseline/`为仅单日。两组分别保存NAV、交易流水、完整配对交易、
主仓交易、信号与指标；`signal_trade_stats.csv`保存实际开仓分支的净胜率与平均收益。
`annual_returns.csv`与`comparison_nav.csv`保存年度收益及逐日净值比较。
`verification.json`记录日历、信号早于成交与单日条件保留检查。
期末未平仓持仓估值但不计入闭合交易胜率，新增买点改变后续交易路径，其逐笔盈亏
不等于组合相对基线的增量收益。

`run_manifest.json`记录请求、配置、费用与执行口径；`inputs/`、`code_snapshot/`、
`source_manifest.json`保存输入、实现与SHA256。年化按365自然日，夏普按243交易日。
100份/股整手、农行税前现金股息及512100份额合并沿用原模型；ETF现金派息未单独记账。
未完整模拟实际股息税、到账延迟、停牌涨跌停及盘口容量。
