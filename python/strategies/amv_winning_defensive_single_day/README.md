# 农行直接防守：仅单日涨幅入场

独立策略 `amv_winning_defensive_single_day`，基于农行直接防守版，仅取消主仓的
所有多日累计涨幅入场分支。主仓512100.SH仅在0AMV**单日涨幅≥4%、收盘≥MA5**
且没有MA10/MACD退出条件时进场。未增加MA30或其他条件。

0AMV收盘离场时全仓转入农业银行601288.SH；主仓单独盘中退出后先持现金。
农行无止损、无J过滤，费用后净价差8%止盈（股息不计入阈值），止盈后持现金直到
有效主仓进场。主仓2.5%硬止损、浮盈超过5%后的实体低点跟踪退出、盘中退出当天
不回买、满仓整手、费用、分红记账和退出优先级均沿用原版。

```bash
./scripts/backtest.sh run strategy amv_winning_defensive_single_day --start 20200102 --end 20251231
```

每次运行使用同一输入和完整主仓日历重跑两日≥4%原版作基线。根目录为仅单日版，
`baseline/`为原版；两版分别保存净值、事件流水、配对交易和指标。
`comparison_nav.csv`、`annual_returns.csv`、`signal_trade_stats.csv`分别保存逐日对照、
年度收益、主仓入场分支胜率与等权平均单笔净收益。`inputs/`、`code_snapshot/`和
`source_manifest.json`保存输入、依赖代码及SHA256，`latest-report.md`是最近成功报告。

新版本与三日版共享输入、报告和对照运行代码，均复用原直接防守成交循环；
各自的入场条件独立定义。配置可用 `--config PATH` 替换，`paths.stock_data`支持
单只农行原价5分钟CSV或本项目股票parquet目录。缺少主仓日期上的0AMV/农行数据时报错。

默认初始资金20万元，区间20200102—20251231。年化按365自然日，夏普按243交易日
与零无风险利率。成交仍是 `legacy_same_close_idealized`，即收盘确定的信号按同日收盘
执行；保留固定旧税费与除息日可用的税前股息。未完整建模实际股息税、到账延迟、
停牌涨跌停成交和盘口容量，结果用于同口径比较，不能直接视为可实盘复制的收益。

2020—2025首次完整回测总收益330.96%、年化27.57%、最大回撤-20.38%、夏普1.711，
原版为288.26%、25.37%、-21.55%、1.467。仅单日版产生32笔已平仓主仓交易，
胜率59.38%、平均单笔净收益2.09%；全账户含农行共58笔已平仓交易。
2025年收益19.77%，低于原版34.81%，并非逐年都优于原版。完整年度数据与记录见最新报告。
