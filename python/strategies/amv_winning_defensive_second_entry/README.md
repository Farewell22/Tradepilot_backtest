# 农行直接防守：增加二类乖离度买点

独立策略 `amv_winning_defensive_second_entry`，在仅单日≥4%的版本上增加第二买点。
第一买点为0AMV单日涨幅≥4%。第二买点为0AMV的MA10>MA30、正MA10乖离度
首次从P60以下进入[P60,P80)，重新进入趋势状态时首次满足也可触发。
两类均要求0AMV收盘≥MA5；离场优先，已有主仓不重复买入。

任一买点有效时全仓整手买入512100.SH；持有农业银行601288.SH则先全部卖出农行。
0AMV低于MA10或MACD死叉时离场转农行；主仓盘中单独触发2.5%硬止损或
浮盈超过5%后按前日实体低点跟踪退出时先持现金。盘中退出当天的主仓买入信号取消。
农行无止损、无周线J过滤，费用后净价差8%止盈（股息不计入阈值），
止盈后现金锁定到下一个有效主仓买点。

共享因子复用 `python/factors/amv_gap.py`，分位数基于当日以前最近至多750个
MA10>MA30状态下的有效观察，至少250个才计算。完整指标预热后再截取回测日期。
当日两种买点都成立时归因于第一买点；交易记录保存信号日及买点标签。

```bash
./scripts/backtest.sh run strategy amv_winning_defensive_second_entry --start 20200102 --end 20251231
```

默认初始20万元。主结果使用 `next_open_amv_abc_t1`：0AMV信号收盘确认，下一共同
交易日开盘执行；主仓买入当天不可卖出。原单日策略仍保留原历史成交时点。
本策略一次运行四组：根目录为次日开盘双买点，`baseline/`为次日开盘仅单日版；
`legacy_same_close/second_entry/`和`legacy_same_close/single_day/`为同日收盘理想化对照。
因此可以分别判断新增买点的影响和成交口径改变的影响。

各组保存NAV、事件流水、完整配对交易、主仓交易、AMV信号及指标。
`signal_trade_stats.csv`按实际信号日归因，报告各买点闭合交易的净胜率和平均净收益；
期末未平仓交易不计入胜率。`annual_returns.csv`与`comparison_nav.csv`保存四组年度和逐日对照。
`run_manifest.json`记录主结果成交口径，子组`metrics.json`记录各自口径。
输入、代码、SHA256保存于`inputs/`、`code_snapshot/`、`source_manifest.json`。

年化按365自然日，夏普按243交易日。费用、农行现金股息及主仓份额合并沿用原模型；
农行股息在除息日计入税前可用现金，ETF现金派息未单独记账。未完整模拟实际股息税、
到账延迟、停牌涨跌停和盘口容量；同日收盘结果具有理想化假设。
新增买点会改变农行和后续主仓的持仓路径，新增分支盈亏不等于相对基线的增量收益。
