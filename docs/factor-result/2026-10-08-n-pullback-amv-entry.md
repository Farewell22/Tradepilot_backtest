# 三轮N型守前低因子：AMV主仓开仓日研究

本次结果不支持把“每轮都守住前低”直接作为正向选股条件。守前低组虽然平均绝对收益为正，但5、10、20日都低于同日全A股等权基准；因子分组没有形成随分数升高而收益升高的梯度。也不能据此直接将因子反向使用：高低分组及守前低/破低的收益差值区间均跨过零。

## 范围与定义

冻结策略运行 `amv_winning_defensive__20260928T143530Z__de469ebc`，只读取其中主仓512100的51个实际买入日：2020-01-02至2025-08-28。股票来自历史当日行情，包括沪深A股及北交所，保留ST；历史上共5,638只有效行情股票进入数据准备，不用当前上市名单替代历史股票池。

结构为 `L0→H1→L1→H2→L2→H3→L3(t)`，高点依次抬高且每段上涨幅度为正。主因子：

`F = min(L1/L0−1, L2/L1−1, L3/L2−1)`。

F≥0表示三轮都守前低，F<0表示至少一轮破低。5%收盘反转确认前序拐点，第三轮只用当时已知低点；252根有效日K窗口，504个市场日预热。没有结构、历史不足等记录是缺失因子。3%/8%阈值为预定对照，没有按结果优化参数。

收益从观察日下一市场交易日复权开盘价，到第5/10/20个市场交易日复权收盘价；缺端点不顺延，收益不含费用。先逐日期计算股票组均值，再日期等权汇总。基准是同日满足252根有效历史的所有股票可用收益等权平均。

## 主要结果

主口径共238,258条股票×日期观察，223,489条满足历史长度，35,243条满足N型结构，其中9,375条三轮均守前低。下面收益均为日期等权的平均收益，百分比；组间差值为百分点。

| 指标 | 5日 | 10日 | 20日 |
| --- | ---: | ---: | ---: |
| 同日全A股基准收益 | 1.5503% | 1.9058% | 3.6611% |
| 守前低组收益 | 1.1892% | 1.5789% | 2.5821% |
| 破低组收益 | 1.4178% | 1.8147% | 3.2752% |
| 守前低组相对基准 | -0.3610 | -0.3269 | -1.0790 |
| 守前低组上涨比例 | 51.1596% | 52.0206% | 51.6791% |
| 守前低组平均MAE | -4.6637% | -6.4013% | -8.8281% |
| Q5−Q1收益差 | -0.4171 | -0.2633 | -0.5679 |
| 平均Spearman IC | -0.0344 | -0.0365 | -0.0411 |
| 重叠窗口时间簇 | 48 | 39 | 24 |

上涨比例是个股收益标签的截面比例再按日期平均，不能当成原策略的逐笔交易胜率。MAE是窗口内最低价相对入场开盘的变化，也不是组合净值波动率。守前低组的平均MAE更负，当前定义也没有显示出更小的窗口内不利波动。

守前低组相对破低组的95%簇bootstrap区间分别为[-0.6230, 0.1539]、[-0.9564, 0.5659]、[-1.5889, 0.1617]个百分点，均包含零。10/20日IC的名义区间低于零，但相关性弱，且未做多重检验校正；不能据此宣称已有可交易的反向alpha。

3%/8%对照的Q5−Q1与守前低−破低均值也均为负，但多数区间跨零。2020—2023有33个事件，2024—2025只有18个事件；后段20日窗口仅8个时间簇，按预定规则不报区间。个别阶段差值会变号，不应仅挑选有利年份。

## 如何解释

当前F衡量的是三轮中最弱的一轮守低程度，并不约束各轮涨跌幅、回调时长或几何对称性。高F有时对应价格迅速抬升后再大幅回落，结构图01就是这种情况。因此，“守前低”与“低成本、浅回撤、节奏均匀的完美回调”不能直接画等号。本次结果仅评价这一明确因子定义在这些AMV开仓日的表现，不否定其他N型定义或其他择时时点。

因子代码可用、口径可复核；当前证据不足以把它作为原策略的正向选股过滤条件。暂时更适合保留为结构诊断变量。若以后扩展研究，应预先定义回调深度、距离前高或回调时长等独立变量，并在新的验证区间检验，不能凭本次结果反复修改“完美”的定义。

## 数据调整与局限

批量请求时Tushare返回40203限频，实际复权来源改为新浪公开历史hfq事件，全部有效股票覆盖通过，没有用未复权价格降级。事件按生效日延续，不以未来乘数改变历史比率。

全量核验发现689009的hfq接口为空。依据[上交所2020年市场资料第23页](https://www.sse.com.cn/aboutus/publication/factbook/documents/c/10170562/files/da4f403a0b7443fa9b2ba2e002d38f10.pdf)，689属于存托凭证，688属于股票，因此修正此前过宽的6开头筛选，按证券类型排除689xxx。原始日线缓存保留，逐日审计记录排除的1,195条CDR记录，准备缓存版本升级为2。

有效日K要求完整48根5分钟K（可另有09:30）；无效日不造价。全A股基准5/10/20日标签分别缺396/541/682条，守前低组分别缺15/21/24条。退市清算、历史ST过滤、涨跌停可成交性及费用未建模；缺失收益不能当零，退市相关缺失可能带来选择偏差。源数据可能被供应商历史修订，没有完整逐时点版本档案。
