# 0AMV 三日动量与沪深300ETF远期收益研究

## 结论

三日动量以 `(0AMV(t)-0AMV(t-3))/0AMV(t-3)` 计算，即三日累计涨跌幅；各样本独立分为十组，Q1最低、Q10最高。全样本中，较高动量相对较低动量仅在10日、30日更占优，且十组收益不严格单调，不能仅凭该因子直接构造单向交易规则。

| 样本 | Q10-Q1：3日 | 5日 | 10日 | 30日 | 组序 Spearman（3/5/10/30日） |
|---|---:|---:|---:|---:|---|
| TRAIN（2015–2023） | -0.11% | -0.30% | +0.39% | +0.10% | -0.07 / -0.10 / +0.02 / +0.08 |
| OOS（2024–2025） | +0.50% | +0.45% | +0.83% | +1.39% | +0.12 / +0.49 / +0.53 / +0.08 |
| 全样本（2012-05-28–2025-12-30） | +0.12% | -0.07% | +0.69% | +0.89% | +0.02 / -0.03 / +0.27 / +0.15 |

- OOS 的 Q10 相对 Q1 在四个周期均为正，10日与30日差异分别为 +0.83% 与 +1.39%。
- 全样本的10日、30日 Q10-Q1 为 +0.69%、+0.89%；3日差异很小，5日为负。
- 所有阶段、所有周期均未出现十组均值严格递增，因此该关系有方向性但不稳定，宜与趋势或估值等状态条件联合检验。

## 研究口径

- 因子：`(0AMV(t) - 0AMV(t-3)) / 0AMV(t-3)`，即三日累计涨跌幅；0AMV数据必须为正。
- 样本：0AMV与510300ETF交易日期交集；TRAIN、OOS、全样本各自独立等频十等分。
- 远期收益：信号日后下一ETF交易日开盘，持有至第 3、5、10、30 个交易日收盘。
- 每个合格日期为一个观察值，远期收益允许重叠；结果是条件收益研究，不是完整持仓回测。
