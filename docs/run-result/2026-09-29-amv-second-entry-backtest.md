# 512100第二买点：实现与2020—2025回测

策略：`amv_winning_defensive_second_entry`。实际区间2020-01-02—2025-12-31，1454个相同交易日，初始资金20万元。主仓512100.SH，防守仓农业银行601288.SH。

第二买点已按要求实现，但这次结果不支持把它当作高胜率补充买点：次日开盘成交下，第二买点17笔完整交易只盈利4笔，胜率23.53%，平均每笔净收益−0.34%。开仓增加，组合收益和夏普下降。

## 规则及代码

第一买点为0AMV单日涨幅≥4%。第二买点为0AMV的MA10>MA30、正MA10乖离度首次进入[P60,P80)，沿用历史买点实现及趋势重新进入的处理。两者均要求0AMV收盘≥MA5、离场优先。分位数仅取此前最近至多750个MA10>MA30有效观察，至少250个预热。

任一买点有效且没有主仓时，全仓整手买入512100；若持有农行先全数卖出。同日两个买点都满足时，归因于第一买点。主仓MA10离场、MACD死叉、2.5%硬止损、盈利超过5%后的前日实体低点跟踪退出均沿用原条件。农行无止损，费用后净价差8%止盈，止盈后现金锁定直到有效主仓进场。

新主结果采用收盘确认后次日开盘成交、主仓T+1。同次运行包含同日收盘理想化对照，原正式策略的默认成交时点保留。代码见 [新策略runner](../../python/strategies/amv_winning_defensive_second_entry/runner.py)、[说明及命令](../../python/strategies/amv_winning_defensive_second_entry/README.md)。

平均每笔净收益为交易收益率的算术平均，不是组合收益。次日开盘第二买点交易的金额盈亏合计为+29,103.17元，与平均收益率−0.34%可以同时成立，因为各次交易投入的资金不同。评估新增条件还需计入被替代的主仓及农行持仓收益，不能将该金额视为相对基线的增量利润。

## 第二买点的主要退出原因

次日开盘结果如下：

| 最终退出原因 | 笔数 | 盈利笔数 | 平均净收益 |
| --- | ---: | ---: | ---: |
| 2.5%硬止损 | 8 | 0 | −2.71% |
| 低于MA10 | 3 | 0 | −1.38% |
| 低于MA10且MACD死叉 | 1 | 0 | −1.93% |
| MACD死叉 | 1 | 0 | −0.45% |
| 盈利超过5%后的实体低点跟踪退出 | 4 | 4 | +5.61% |

这说明13/17笔在本策略风控下没有形成盈利退出；4笔趋势延续的交易虽然盈利，但不足以获得高胜率。与此前510300的53.85%/66.67%不同，512100的波动、2.5%止损和AMV退出条件共同形成了本次结果。尚未单独对照止损阈值，不能只凭8笔止损就断言放宽止损会改善策略。

第二买点按买入年份归组：2020–2023共13笔、2笔盈利，胜率15.38%、平均净收益−0.81%；2024–2025共4笔、2笔盈利，胜率50%、平均净收益+1.18%。后期已被此前研究观察且样本少，不能视为独立验证。
