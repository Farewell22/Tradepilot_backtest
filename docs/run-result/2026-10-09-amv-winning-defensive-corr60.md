# 0AMV防守策略：进攻仓选择60日相关性第一名

## 结论

新策略已实现并完成2019-01-18至2025-12-31全区间回测，共1,685个共同交易日。
仅将固定512100进攻仓替换为每次实际开仓时相关性最高的ETF，其余规则、费用、成交口径保持。
两个防守版本均小幅改善收益和最大回撤；改善不是每年都出现，2022、2023、2025年均跑输原版。

**这是探索性结果：固定股票池按完整未来历史筛选，存在前视偏差；同日收盘信号与成交属于理想化假设。不能将该结果解释为严格无前视验证或实盘可实现收益。**

## 股票池与交易规则

- 1,383只本地ETF重新审计，固定保留1,284只，99只因完整历史至2025-12-31存在超过25%的相邻有效收盘或隔夜开盘价格断点而剔除。
- 逐日完整60分钟K线、OHLC和正成交量校验；完全重复行去重，无效日只屏蔽当天和污染因子窗口，不额外整只剔除。
- 名称归一化去重，保留因子有效、最早出现有效行情的代表；它只是官方指数映射/上市日的代理。
- 截至开仓当日收盘，计算60对完整ETF日收益率和0AMV日变化率的Pearson相关性；最高相关系数优先，不取绝对值，也不额外设正相关门槛；同分按代码排序。
- 只在实际开进攻仓时选股，持仓期间不轮动，清仓后再开仓重新选择。无候选则保留防守或现金；最终本次62次选择均有合格标的。
- 进攻仓2.5%硬止损、超过5%后实体低点跟踪止盈、0AMV入退场优先级、盘中退出当天不再进攻、两个防守版本规则保持原版。
- 初始20万元、满仓、100份/股取整；ETF佣金万三、最低5元、单边滑点千一；农行另计股票印花税和过户费，公开分红及8%净价差止盈保留。
