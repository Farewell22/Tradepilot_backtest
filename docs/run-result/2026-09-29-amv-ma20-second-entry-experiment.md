# 512100第二买点实验：MA20上穿后5日确认

实验日期：2026-09-29。策略：`amv_winning_defensive_ma20_entry`。区间：2020-01-02—2025-12-31，共1454个相同交易日；初始资金20万元。主仓512100.SH，防守仓农业银行601288.SH。

## 1. 结论

**这次实验没有通过“增加高胜率主仓机会”的目标，不建议正式加入这个第二买点。**

MA20确认分支实际开仓8笔，仅1笔盈利，胜率12.50%，平均每笔费用后收益−1.12%。组合主仓开仓从32次增加到38次，总收益由391.21%下降到320.69%，最大回撤由18.49%扩大到20.82%。基线的1454行净值和所有买卖、配对交易、主仓交易、信号记录均与上一轮冻结基线逐行完全一致。

新策略留作独立实验入口，原单日策略和P60–P80实验的交易规则没有改变。上一轮P60–P80第二买点17笔胜率23.53%；本次改为MA20确认也没有获得高胜率，现有证据不支持继续无条件叠加入场分支。

## 2. 固定的实验规则

第一买点保留0AMV单日涨幅≥4%。第二买点为：

1. 前一日0AMV收盘不高于MA20，当日高于MA20，开启候选。
2. 上穿日算第1个交易日，从第1日至第5日首次同时满足三日累计涨幅 `close(t)/close(t-3)-1 > 4%`、当日收盘>MA60时确认。第6日起失效。
3. 两个买点都须收盘≥MA5。离场优先，已有主仓不重复开仓；同时满足两类时归因原单日条件。
4. 收盘确认后，下一共同交易日开盘执行。持有农行则先卖出全部农行，再全仓整手买入512100。主仓买入日不可卖出。

退出完全复用当前农行直接防守模型：0AMV低于MA10或MACD死叉优先离场、转农行；主仓2.5%硬止损、盈利超过5%后按原规则激活前日实体低点跟踪退出。盘中主仓退出取消当天的主仓买入信号。农行无止损，费用后净价差8%止盈（股息不计入阈值），止盈后持现金直到有效主仓买点。

只比较这一套5日窗口，没有根据本次结果继续调整窗口或止损。共享确认因子按日期推进，信号在实际确认日产生，不回填到上穿日；计算全历史后再截取回测区间。

## 6. 为什么新增分支亏3千元，组合却少赚14万元

完整账本可对上：

| 资产腿 | 基线已实现盈亏 | 实验已实现盈亏 | 差额 |
|---|---:|---:|---:|
| 512100主仓 | +318,025.95元 | +274,878.05元 | −43,147.90元 |
| 农行防守 | +464,394.92元 | +366,510.59元 | −97,884.33元 |
| 合计 | +782,420.87元 | +641,388.64元 | −141,032.23元 |

新增买点改变后续本金、原买点是否还能执行，以及农行何时买入和卖出。不能把新增分支的−3,261.73元当作整个组合的增量影响。

两组有19笔农行交易的买入日期、卖出日期和退出原因完全相同，收益率最大差异仅约4.4×10⁻¹⁴个百分点，金额盈亏却合计少68,949.68元，说明此前路径造成的本金差异会影响后续同样涨幅的收益金额。其余农行交易还包含路径、持仓长度和仓位变化，不能把全部97,884.33元差额简单归为提前卖出农行的独立机会成本。
