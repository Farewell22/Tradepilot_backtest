# MA5上穿弱信号：动态进攻仓回测总结

运行：`amv_winning_defensive_corr60_ma5__20261009T064143Z__19572b6f`；2019-01-18—2025-12-31，1685个共同交易日，初始20万元。

## 规则

保留原高质量入场和原强仓退出。新增弱信号为0AMV严格上穿MA5、且不满足原高质量条件；不设MA60和最低涨幅门槛。实际开仓选择当日60日收益相关性最高ETF，全仓；持仓不按排名轮动。

弱仓按开仓日0AMV涨幅冻结净止损/止盈：<1.5%为−1%/+1.5%；[1.5%,3%)为−1.25%/+2%；≥3%为−1.5%/+2.5%。阈值包含双边费用及滑点。最迟买入后第3个共同交易日收盘退出。跳空按开盘，同根双触价止损优先，买入当日不盘中卖出。

弱仓遇原强信号时原ETF升级，不交易、不重置成本。顺序为盘中退出→AMV收盘退出→升级→时间退出；退出日禁止重开进攻仓。升级当天只用收盘新激活5%利润保护。

## 结论

- 512890.SH：ma5相对原版总收益变化-45.220个百分点，年化变化-4.090个百分点；最大回撤绝对值变化+12.611个百分点；相对control总收益变化-20.767个百分点。
- 601288.SH：ma5相对原版总收益变化-181.725个百分点，年化变化-7.925个百分点；最大回撤绝对值变化+3.426个百分点；相对control总收益变化-44.030个百分点。

本次参数下，增加次数未带来更高收益，两个防守版本均较原版收益下降、回撤扩大，暂不建议替换原版。新版53笔弱入场交易的平均净收益为−0.128%，胜率33.962%；5笔升级。control弱入场51笔、升级15笔，紧退出减少了升级机会。新版55次直接高质量买入，原版62次；原条件保留不代表原交易序列保留。13个高质量信号日因当天已退出而被阻挡，该数量不是13笔确定可获利的遗漏交易。

更频繁交易增加费用，并改变防守仓持有时间；2022、2023、2025年新版相对原版明显减弱。下一步若继续研究，应单独验证弱信号的收益基础，采用预先固定规则和样本外检查。

## 验证与限制

- 453项Python测试通过，2条既有FastAPI弃用提示；22项覆盖本策略。整体只读审查未发现默认规则执行/记账缺陷。
- 两个baseline版本的NAV及原交易列与此前完整corr60回测逐行一致。2024年代表运行及完整运行均通过统一入口。
- 固定池为1284/1383只，按截至2025年末全历史排除99只疑似25%价格断点ETF，存在事后筛选前视偏差；名称代理去重不等同于官方指数映射。
- 同日收盘信号、因子和成交采用legacy_same_close_idealized理想化口径。原始ETF价格无完整复权/现金分红，60分钟触价先后和盘口成交约束未完全模拟。
- 结果属于探索性比较；不能据此认定可实盘复制。没有依据结果重新挑选参数。
