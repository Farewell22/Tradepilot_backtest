# 0AMV相关性第一名ETF策略复盘：2019—2025

## 摘要

开进攻仓时选取与0AMV过去60日日收益变化相关性最高的ETF，两个防守版本整体小幅改善；收益优势并不逐年稳定。两版均在2022、2023、2025年跑输固定512100基线。
**该结论仅适用于本次探索性回测：固定无异常ETF池按未来完整历史筛选，存在前视偏差；使用同日收盘理想化成交。**

## 1. 执行口径与数据来源

- 运行：`data/backtest_runs/amv_winning_defensive_corr60__20261009T055547Z__c55b8dd0`；任务`amv_winning_defensive_corr60`，状态`complete`。
- 区间2019-01-18—2025-12-31，1,685个共同交易日，初始20万元。基线和新版使用相同数据、日历与费用。
- 固定无异常候选池：本地1,383只ETF中保留1,284只，剔除99只完整历史中存在超过25%相邻有效收盘或隔夜开盘断点的ETF；筛选截止2025-12-31。
- 因子本身只使用开仓当日及以前的60对日收益，名称代理去重、最早有效行情选代表。实际开仓选择第一名，持仓不轮动；新版62次进攻仓买入，共26只ETF。
- 两种防守版本进攻仓买入日期及ETF一致，金额因资金路径不同而不同。原版61次开仓；不同止损路径会改变新版实际开仓日期。
- 成交口径`legacy_same_close_idealized`：当日收盘信号/因子按当日收盘成交。ETF佣金万三、最低5元、单边滑点千一；农行额外股票印花税千一、过户费十万分之一。
- 整体指标以根目录`metrics.json.variants`为准；年化按365自然日折算，夏普按243交易日折算。交易归因以各版本`paired_trades.csv`为准，年度收益以`annual_returns.csv`为准。
- 已运行技能统计脚本。顶层四腿NAV/variants结构不被脚本完整识别，故未采用其顶层推导指标；分别分析四个子目录。子目录没有独立manifest，执行口径和请求区间由根清单补齐；脚本FIFO恢复交易仅作辅助，原生配对流水作为归因依据。
- 本轮只读取已有运行及代码并撰写复盘，没有改策略或重跑回测。

### 极端盈利：159903，2024-09-24—2024-10-09

## 8. 可证伪的归因结论

1. **正向迹象具有时期依赖。** 两版4/7年跑赢，但2023年分别少赚8.11/9.98个百分点。若相关性排序稳定有效，应在预先固定、无事后异常排除的未来区间也改善年化和回撤；否则本次优势不足以外推。
2. **选第一名未减少硬止损。** 22次硬止损没有下降，改善伴随跟踪止盈19→24次。假设分散持有相关性前3名能减少单ETF噪声，可固定其他规则验证硬止损频率和组合回撤是否下降；未验证前不认定优于第一名。
3. **大趋势交易对盈利贡献集中。** 159903的2024年单笔对农行进攻平仓利润贡献约48.4%、红利版约40.1%；这些比例是现金平仓贡献，非对年度NAV回报的独立归因。若稳健性强，删去该极端交易或分时期报告后，优势不应完全消失。
4. **防守选择改变总体资金路径。** 农行新版防守平仓贡献425,012.92元，进攻374,895.23元；高收益不能全部归于ETF相关性。用进攻交易净收益率而非不同本金的现金盈亏比较，可检验选择本身的贡献。

## 9. 优化建议：仅提出验证方案

### 可立即验证（另行使用 strategy-backtest-development）

- 固定现有全部规则，增加相关性前3名等权组合对照；预期降低单只集中风险，考察最大回撤、硬止损频率和费用，不能只挑总收益赢家。组合止损口径需在实施前明确。
- 将硬止损2.5%与3.5%作预先固定的单参数对照，跟踪止盈不变；检查3日内退出减少多少、平均亏损和最大回撤增加多少。此建议来自短期退出样例，尚不能断言改善。
- 做当日收盘信号次日开盘成交的独立对照，原同日收盘版保留；测量价格与数量路径差异，尤其复核2024年159903的阈值卖出交易。预期揭示实际可执行性，而非保证收益更高。

### 需先研究（factor-research）

- 用当时可知的历史异常记录形成动态候选池，核实持仓遇到拆合份额时的记账，消除完整未来历史筛池偏差；再比较因子IC及分组收益是否保留。
- 研究相关性排名优势是否随ETF波动率或市场状态变化，检验绝对相关值、第一与第二名分差是否能提高可预测性；阈值必须在早期数据确定，后期验证，不按本次亏损年份倒推过滤器。
- 研究159836等高频亏损标的是否由波动特征解释，使用全候选池验证；不能仅凭本次现金贡献表建立黑名单。
