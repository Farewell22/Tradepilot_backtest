## 对照口径

直接版沿用amv_winning_defensive：仅0AMV收盘离场买银行；主仓仅盘中止损后持现金；银行按扣买卖费后的净价差8%止盈，分红不计入阈值；止盈后现金锁到主仓有效进场；主仓盘中退出当日不再进场。

J版沿用amv_winning：实际主仓卖出后开启观察，本股当日动态周线KDJ(9,3,3)的J严格小于10才买；实际买价上涨8%止盈、目标向上取整至分；止盈次日可继续观察；主仓盘中卖出当天可按有效信号重入。有效主仓进场优先卖所有银行买主仓，冲突时离场优先。两版差异不只是J过滤。

银行原价执行、税前股息一次入账，本股2019年历史预热、已发生分红连续指标；未模拟个人股息税、税率历史变化、停牌涨跌停成交/容量。保留同日收盘理想化成交，不能直接当作实盘可复制收益。末日按收盘估值而非强制平仓。年化按实际日历间隔和365天复利，夏普Rf=0/243日。
