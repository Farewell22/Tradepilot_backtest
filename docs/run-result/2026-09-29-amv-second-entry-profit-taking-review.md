# 第二买点为什么拖累：是否止盈不及时

复盘日期：2026-09-29。结论是：**止盈不及时不是主要原因。在本次实际持仓窗口内，多数第二买点交易没有形成足够的上涨；少数小浮盈回吐可以单独验证保护规则，但不能据此认为提前止盈能解决整体拖累。** 组合差额还包括农行持仓被改变，以及早期净值落后导致后续投入本金减少。

本轮只读取已有回测、输入快照和执行代码，未改变策略、未重跑策略回测。高点观察是交易复盘，不是“按事后最高价卖出”的模拟收益。

## 当前止盈到底如何工作

主仓不是达到5%就固定卖出。代码在买入日之后检查当日最高价是否超过执行买价的105%，达到后激活跟踪退出；以后按前一日ETF实体低点检查跌破退出。收盘确认的0AMV低于MA10或MACD死叉则次日开盘优先离场。

对应代码：[主仓止损与实体低点退出](/home/wang/workspace/TradePilot_backtest/python/strategies/amv_winning_defensive/runner.py:259)、[5%激活检查](/home/wang/workspace/TradePilot_backtest/python/strategies/amv_winning_defensive/runner.py:301)、[AMV离场和全仓轮换](/home/wang/workspace/TradePilot_backtest/python/strategies/amv_winning_defensive/runner.py:202)、[买点分类与归因](/home/wang/workspace/TradePilot_backtest/python/strategies/amv_winning_defensive_second_entry/runner.py:33)。本次代码与当次快照一致。

5%激活用执行价格涨幅，不是扣除全部费用后的净收益。下文峰值浮盈采用费用后净收益，不能与5%激活门槛直接混用；不过这13笔亏损交易的净浮盈峰值都不到2%，差距远大于费用差异，因此均没有出现“先获得5%级别浮盈，之后回吐成亏损”的过程。

## 入场后有没有足够利润可以保护

逐笔最高浮盈以实际买入成本为分母，以持仓期间某个价格下按原卖出费用清仓所得为分子。买入当天虽然可以观察价格，但T+1不能卖出，所以主要统计从下一交易日起、实际退出以前的可卖出期间。

次日开盘离场的交易不使用退出当天开盘后的高价。盘中止损或跟踪退出所在60分钟K线的高低先后未知，因此记录上下界：下界只用此前完整K线的高点、退出K线开盘价及实际退出价，上界允许该退出K线最高价；若实际按跳空开盘价退出，则不纳入该K线后续最高价。

4笔盈利交易的平均最高净浮盈为6.56%—6.62%，最终平均净收益5.61%，平均回吐约0.95—1.00个百分点。确有回吐，属于现有跟踪退出容许的波动范围；它们全部以盈利退出，没有利润大幅回吐成亏损。

同日收盘双买点的11笔亏损中，仅3笔峰值净浮盈达到1%，其中1笔达到2%，没有任何亏损交易达到3%。两种时点下都不能把多数亏损归因于未及时锁住大额浮盈。

不能把这些峰值当作可实现的回测收益。它们是对已发生交易的事后价格空间检查；改止盈后，持仓、后续开仓、农行本金和收益都会改变，必须另行完整回测。

## 归因结论

1. **多数亏损不是大额浮盈回吐。** 13笔亏损中11笔峰值净浮盈不足1%，没有任何亏损笔达到净2%；降为净2%或3%固定止盈，在原持仓价格路径上仍无法触发于这些亏损笔。可证伪点是更低门槛的保护是否能在完整组合中改善平均净收益，而非只提高点估计胜率。
2. **第二买点的上涨延续弱于第一买点。** 峰值净浮盈中位数0.58%对4.11%，止损和AMV失效退出占13/17。二类是宏观趋势与乖离状态，不等于512100必然启动；是否需要更明确的启动确认是待验证假设。
3. **5%跟踪退出保护了已经走出来的趋势。** 4笔盈利最终平均+5.61%，平均只回吐约1个百分点。降低固定止盈会同时截短这些盈利，需兼顾胜率、盈亏比和组合收益。
4. **复利本金差是重要放大器。** 21笔相同路径、相同收益率的农行交易少赚约7.80万元，证明最终差额不能全部解释为新增17笔直接盈亏或农行卖点问题。
5. **简单均线过滤未显示足够解释力。** 以份额合并调整后的ETF价格检查信号日，有16/17笔第二买点的512100在自身MA30上方，其中只有3笔盈利；唯一不在MA30上方的交易反而盈利+5.84%。这组小样本不支持把“512100>MA30”当作现成修复。检查MA10>MA30也只排除1笔亏损，不能解释主要失败。

## 优化建议

可立即验证，均属于 `strategy-backtest-development`，本轮未实施：

- 只给第二买点设置较低的盈利保护，比较“固定净1%止盈”或“价格浮盈超过2%激活跟踪退出”与现状，第一买点不变。重点统计两笔小浮盈回吐是否改善，同时检查4笔原盈利是否被截短。预期影响来自小样本假设，不承诺能提高整体收益。
- 将第二买点改为小仓位试探，保留其余资金的农行/现金状态；比较组合收益和最大回撤。这能检验降低失败入场的组合影响，但不会直接改善信号自身胜率，也会改变当前全仓策略。
- 若怀疑2.5%止损过紧，单独比较第二买点的原止损与更宽止损，止盈保持不变，逐笔记录更宽止损后是恢复盈利还是扩大亏损。不能同时调止损、止盈和买点后只报告最优版本。

需先研究，属于 `factor-research`：

- 固定二类定义后，研究第二买点的强度确认，例如0AMV短期增量速度或512100自身的突破/上涨延续。应先选择研究收益期限，处理重叠事件和样本量，再决定过滤规则；不继续无依据叠加MA30条件。
- 使用尚未参与本轮选参的数据检查信号及保护规则。2024—2025只有4笔第二买点，且已经被观察，不能当成独立样本外证明。

## 局限与可复核产物

样本仅17笔。结论只涉及实际交易的入场到离场窗口，不证明止损之后不会再涨，也不证明这个信号在其他持有期限、标的或止损条件下必然无效。60分钟高低价先后未知，最高浮盈只是理论价格空间；买入日因T+1不算可卖出窗口。部分AMV离场于次日开盘，实际盈亏包含隔夜变化和跳空。

ETF现金派息未单独记账，保留固定旧税费、农行股息除息日可用等假设；未完整模拟股息税、到账延迟、停牌涨跌停及成交容量。同日收盘对照另含理想化成交假设。资产金额分解是对两条完整历史路径的会计归因，不是隔离其他变量的因果实验。
