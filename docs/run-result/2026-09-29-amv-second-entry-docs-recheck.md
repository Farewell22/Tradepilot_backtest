# 512100第二买点：重新核对现有文档与历史交易

分析日期：2026-09-29。范围：`docs/factor-result/`、`docs/run-result/`、`docs/report/` 及相关已有交易文件。用户限定新增买点仍只买512100，主仓退出沿用当前单日版。本次没有修改策略或重跑回测。

## 1. 结论

**现有文档中还有第二买点候选，但没有另一个已经证明能在当前512100退出规则下增加高胜率交易的买点。**

此前加入的P60–P80第二买点已经实现并完成回测：2020—2025次日开盘口径下17笔完整交易，4笔盈利，胜率23.53%、平均净收益−0.34%。它没有通过用户要求的高胜率验证。仅单日≥4%基线同口径32笔，胜率65.62%。详见 [双买点回测](2026-09-29-amv-second-entry-backtest.md) 和 [逐笔止盈复盘](2026-09-29-amv-second-entry-profit-taking-review.md)。

如果继续测试另一项已有文档候选，可选 **0AMV上穿MA20后，在5个交易日内等待三日动量与MA60确认**。选择它是为了检验不同的启动条件，并非因为它已经表现出足够高的完整交易胜率。

## 2. 尚未加入本次512100策略的候选：MA20上穿后确认

来源：[0AMV因子研究与510300回测说明，第5.2节](../report/2026-09-03-0AMV因子研究与510300回测说明.md)。现有实现：[AmvSignalDetector](../../python/strategies/etf_amv/strategy.py:25)。

规则如下：

1. 0AMV由前一日不高于MA20变成当日高于MA20，开启确认窗口。
2. 从上穿当日起计算5个交易日，首次同时满足三日累计涨幅 `close(t)/close(t-3)-1 > 4%`、0AMV收盘高于MA60时产生信号；未确认则候选失效。
3. 用于当前512100策略时仍须保留收盘≥MA5、离场优先、已有主仓不重复买入；收盘确认后次日开盘执行。
4. 原单日≥4%分支优先，新增分支必须单独归因，主仓退出与农行8%止盈保持同口径。

它检测的是均线突破后的动量恢复，与P60–P80的相对历史乖离位置不同。三日涨幅超过4%也可能出现在当日小幅下跌时，因此不能把它称为已确认的512100强启动。

## 4. 其他文档候选为什么暂不直接采用

| 候选 | 现有证据 | 判断 |
|---|---|---|
| 上穿MA10、三日涨幅>4%的旧次级信号 | 510300独立训练14笔、胜率64.29%，后期4笔、胜率25%；加5日MA60确认版本训练11笔、胜率27.27% | 跨阶段不稳定，不能只取64.29% |
| P30–P35且MA3上行的低乖离恢复 | 较新510300结果训练5笔、胜率60%、总收益−0.13%；后期1笔亏损 | 样本不足，既不能称高胜率，也不能称超跌买点 |
| P40–P60温和趋势买点 | 较新510300结果训练31笔、胜率45.16%；后期4笔、胜率50% | 没有支持当前高胜率目标的证据 |
| 严重死叉后三日≤−4%，红利短持 | 510880完整交易10笔、9笔盈利 | 买的是红利ETF，不满足只新增512100机会的要求 |
| 低成交额、RS20、滚动相关性轮动 | 大部分是行业ETF截面选取或轮动，后期实际交易较少 | 不能直接当作固定512100的入场证据 |
| B1个股研究 | 样本来自预筛选个股、固定期限收益标签 | 不是512100从入场到现有规则离场的净胜率 |

低乖离和温和趋势的较新数字以 `data/backtest_runs/etf_510300_ma10_above_ma30_gap_signal/summary.csv` 为准，相关说明文档的部分旧数字对应早期运行。原次级独立结果见 `etf_510300_0amv_compare/secondary-only/`；5日确认次级结果见 `etf_510300_0amv_window_ma60_compare/secondary-only/`。

另需区别两种窗口：[买点定义对比分析，第8节](../factor-result/2026-09-01-0AMV买点定义对比分析.md) 建议的“买点触发后5日有效”是个股开仓许可窗口，不是上述“均线上穿后等待动量确认”。将原单日≥4%信号延长有效期、用于512100回踩再入场，是可研究的新假设，现有文档没有其完整交易验证。

## 5. 后续比较应如何判定

正式加入之前，需要同区间、同费用、同次日开盘及T+1口径比较当前单日基线与新候选。原单日条件同时成立的交易继续归入第一买点，只统计新增分支独立触发的完整持仓净胜率、平均净收益与年度分布。

组合层面还需比较净值、回撤和农行收益变化。候选有正向ETF交易收益，也可能因提前卖出农行、降低后续本金而拖累组合。现有P60–P80复盘已经体现了这种影响。因此不能只以“多开了几次仓”或某个远期上涨比例作为采用依据。

此次结论是：MA20上穿后5日确认可以进入下一项对照验证，但目前不建议把任一未验证候选直接设为新的全仓第二买点。

## 6. 后续实验结果

用户随后授权开展MA20确认实验，完整结果见 [MA20第二买点实验](2026-09-29-amv-ma20-second-entry-experiment.md)。2020—2025同口径下，该分支实际8笔、1笔盈利，胜率12.50%、平均净收益−1.12%；组合总收益320.69%，低于单日基线391.21%，最大回撤也扩大。前述9个静态潜在日期中，2022-12-05因此前已建立主仓而没有重复开仓。因此这一候选也未通过本次高胜率目标验证，不建议据此正式加入。
