# amv_winning_defensive 策略复核

复核日期：2026-10-08。范围：当前工作区代码、统一入口、策略文档、相关测试，以及 2020-01-02 至 2025-12-31 的重现验证。未修改策略、费用或成交规则，未覆盖 latest-report.md。

## 结论

当前代码能重现已有报告的 NAV 和逐笔交易，但这不等于实盘可复制，也不能把防守版相对现金基线的收益差全部归因于防守资产。首要问题是同日收盘理想化成交、现金基线与防守版的主仓再入场规则不同，以及使用共同交易日交集删除正常交易日。

## 实际规则

- 两个独立账户：512100.SH 与 512890.SH 轮动，或 512100.SH 与 601288.SH 轮动；不是同时配置两个防守资产。初始资金默认 20 万，按整百份/股尽量满仓。
- 主仓入场：0AMV 单日涨幅 >=4%，或两日累计涨幅 >=4%，且收盘 >=MA5。两日累计使用 close[t]/close[t-2]-1，不是简单相加。
- 0AMV 离场：收盘 <MA10（持续状态），或 DIF 从 DEA 上方/相等转为下方（当日交叉事件）。离场优先于买入；按当日最后一根行情收盘价卖主仓并买防守资产。
- 不要求此前实际持有主仓：空仓遇到离场条件，也可以买防守资产。
- 主仓盘中退出：以含买入滑点的参考成交价下方 2.5% 为硬止损；持仓日最高价严格超过参考价 5% 后，于日末启用后续交易日的昨日实体低点退出。实体低点为 min(日开盘, 日收盘)，不是昨日最低价，也不是只升不降的止损线。
- 主仓盘中退出后取消当日主仓买入；当日若有0AMV离场条件，仍可买防守资产。
- 农行从买入次日起，达到扣除买卖费用后的净价差收益 +8% 即卖出；股息不计入阈值。跳空超过目标按开盘价，否则按目标价。卖出后锁定现金，直到下一次有效主仓买入。红利低波没有该止盈，两种防守资产均无独立止损。
- 农行股息在除息日开盘处理前计入现金，以当时已有持仓估算资格，没有单独的登记日与到账日账本，未扣股息税；红利低波现金分红按零处理。份额合并/拆分使用代码中固定事件。
- 主仓与农行的盘中退出均限制为买入后的日期；这不代表已完整模拟停牌、涨跌停或盘口容量。

## 问题与证据

### 1. 高优先级：收盘确认信号却按同日收盘成交

`runner.py:301` 使用当日0AMV完整收盘信号，并按当日资产收盘价成交。统一入口已标为 `legacy_same_close_idealized`，属于已知限制，而非本次新发现的隐藏口径。当前正式入口没有启用函数内部的 next_open 选项。

影响：结果不能作为同口径实盘收益预期；滑点不能消除信息尚未可知的问题。需要独立的次日开盘对照，不能直接覆盖旧策略口径。

### 2. 高优先级：现金基线与防守版的主仓再入场规则不同

防守版 `runner.py:295` 在盘中退出后令当日 buy_signal=False；现金基线 `amv_winning/runner.py:347` 仍可按当日有效买点买回。

确定性复现：10元买入，次日最低9.7元触发9.75元硬止损、收盘10元且买入信号仍有效。零费用下，现金基线收盘重新持有9700份，防守版收盘持有0份。

历史现金基线中，2020-02-25、2020-07-08、2021-04-20、2024-02-20、2024-02-27、2024-10-09存在盘中退出后当日买回。故收益差同时包含防守持仓和再入场规则的影响。应增加主仓规则完全一致的现金对照，保留旧基线。

### 3. 高优先级：防守资产缺行情会删除整个市场交易日

`runner.py:136` 与 `runner.py:355` 起按0AMV、主仓和防守资产行情求日期交集。主仓正常交易而防守资产无行情时，主仓止损、日末信号、估值以及可能的分红处理也会跳过。

确定性复现：只删除防守资产在主仓跌破止损当天的行情，主仓的止损卖出随之消失。应使用主交易日历，区分数据缺失与真实停牌，分别处理各资产可交易状态。

本次历史输入实际删掉2021-10-22。单独为现金版和农行版恢复该日后，两者最终收益均未变化，该日也未出现交易。因此已验证结构性风险，不能声称该日已经抬高本报告的最终收益。删除日仍会改变日收益序列及可能的统计口径。

### 4. 中优先级：股票税费覆盖参数未传入农行

`runner.py:347` 重新创建 stock_legacy，只继承佣金、最低佣金和滑点。统一入口传入的 stamp_duty_rate、transfer_fee_rate 没有进入股票费用对象。

确定性复现：传入全部为零的 FeeConfig，输出 metrics 中 ETF 全零，但农行仍为印花税0.001、过户费0.00001。当前默认历史报告受此问题影响为零；自定义费用敏感性实验可能失真。需要明确分资产覆盖规则，避免把ETF默认零税费误当成股票零税费。

### 5. 已知限制：分红与盘中数据完整性

分红依赖除息日仍在模拟日历且该日开始时持仓，缺少登记日资格与实际到账日的独立记录；红利低波分红未纳入。不能据此作精确的总收益对照。

历史 runner 不验证每天是否有完整60分钟/5分钟K线，最后一根缺失时可能把更早价格当作日收盘，盘中缺失可能漏掉退出。2026准备脚本另有完整性检查，但不会自动覆盖所有历史配置。
