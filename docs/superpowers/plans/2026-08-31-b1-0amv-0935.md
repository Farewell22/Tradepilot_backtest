# B1 + 0AMV 09:35 Backtest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an isolated, point-in-time B1 backtest that compares five 0AMV opening gates at 09:35 across training and out-of-sample stages.

**Architecture:** Keep old backtest behavior untouched. A dedicated strategy module derives lagged AMV gates, selects a 09:35 entry from score-ranked B1 candidates, and owns fixed-position exits. A separate runner orchestrates independent portfolios and artifact directories while reusing data loading, B1 scoring, cost calculations, metrics and reporting.

**Tech Stack:** Python 3.12, pandas, PyYAML, pytest, existing `DataLoader`, B1 filter, metrics and report modules.

**Spec:** `docs/superpowers/specs/2026-08-31-b1-0amv-0935-design.md`

## Global Constraints

- T-day 09:35 buy eligibility can use final data through T-1 only; never T daily bars, B1 ratings, AMV values or future data.
- `baseline`, `gap_positive`, `rank_60`, `rank_80` and `ma20_mom3_gt4` differ only in their 0AMV opening-gate predicate. The latter requires 0AMV strictly above MA20 and a strictly greater-than-4% three-day momentum, both from T-1.
- Buy exactly at 09:35 bar close, at most once daily; use at most four initial-25%-capital, 100-share-rounded positions.
- Exit priority is 5% stop loss, profitable previous-day-body take profit, then T+10 final valid five-minute close; use the existing cost functions for all executions.
- Do not modify the old runner, `TimingSignal`, or old simulator behavior.
- Run tests with `/home/wang/python_env/B1_RATE/bin/python -m pytest`.
